
# 快速入门

## 简介

本仓库包含对 [RaBitQ](https://github.com/gaoj0017/RaBitQ)（SIGMOD 2024）开源项目的 ARM64 平台优化补丁，涵盖**等价索引优化**和**非等价索引优化**两个方向。

RaBitQ 是一种面向高维向量近似最近邻搜索（ANN）的随机二值量化方法，能将 D 维向量量化为 D 位二进制字符串，并提供理论误差界。原始实现基于 x86\_64 AVX2 指令集，本补丁将其扩展至 ARM64（AArch64）架构，并引入多项性能优化。

## 补丁概览

| 补丁文件 | 类型 | 说明 |
|---------|------|------|
| `0001-rabitq-optimize-neq.patch` | 非等价索引优化 | 引入 SOAR 算法，允许向量被分配到多个聚类簇，提升召回率 |
| `0002-rabitq-optimize-eqv.patch` | 等价索引优化 | 在保持算法等价性的前提下，针对 ARM64 平台深度优化搜索性能 |

## 前置条件

- ARM64（AArch64）架构的 Linux 环境（x86\_64 也可编译运行，但无法启用 ARM 优化）
- Eigen 3.4.0（将 `Eigen` 文件夹放置于 `./src/` 下）
- HDF5 开发库（`libhdf5-dev`）
- Python 3.8+，numpy，faiss，tqdm，h5py
- 支持 NEON 指令集的编译器（推荐 clang++ 14+）
- ARM64 可选依赖：jemalloc（内存分配优化）、treelite + tl2cgen（ML 模型导出，仅非等价优化需要）

## 应用补丁

以 RaBitQ 开源代码为基础，应用补丁：

```bash
# 克隆原始 RaBitQ 代码
git clone https://github.com/gaoj0017/RaBitQ.git
cd RaBitQ

# 应用非等价索引优化补丁
patch -p1 < ../0001-rabitq-optimize-neq.patch

# 或应用等价索引优化补丁（二选一，不可同时应用）
patch -p1 < ../0002-rabitq-optimize-eqv.patch
```

## 快速运行

应用补丁后，推荐使用 `run.sh` 脚本统一管理全流程：

```bash
# 等价优化：数据生成 + 索引构建 + 搜索
./run.sh sift fastscan all

# 非等价优化：数据生成 + 索引构建 + ML 训练 + 搜索
./run.sh sift fastscan all

# 也可分步执行
./run.sh sift fastscan generate   # 生成 IVF 聚类 + RaBitQ 量化数据
./run.sh sift fastscan index      # 构建索引
./run.sh sift fastscan train      # [仅非等价] 生成 ML 训练数据
./run.sh sift fastscan eval       # [仅非等价] 训练 LightGBM 模型
./run.sh sift fastscan search     # 执行搜索
```

支持的数据集：`sift`、`deep`、`glove`、`fashion`、`gist`

更多 `run.sh` 的详细使用方法请参见《[用户指南](用户指南.md)》。

## 手动执行

```bash
# Python 索引阶段
cd data
python ivf.py <hdf5_path> <dataset> <K> <metric_type> <soar_lambda>
python rabitq.py <hdf5_path> <dataset> <K> <metric_type> <soar_lambda>
cd ..

# C++ 索引构建
./bin/index_<dataset> -d <dataset> -s <source> -p <hdf5_path> -m <metric_type> -a <soar_lambda>

# C++ 搜索
./bin/search_<dataset> -d <dataset> -s <source> -r <result_path> -k <topk> -n <nprobe> \
    -p <hdf5_path> -m <metric_type> -t <threshold> -e <pred_nprobe> -a <soar_lambda>
```
